# NTE Piano Macro - Quick Start Guide

## 🚀 Quick Start (English)

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Download a MIDI file** (or use the included Orange.mid)

3. **Run the script:**
   ```bash
   python NTEscript.py
   ```

4. **Follow the prompts:**
   - Select language (1 for Spanish, 2 for English)
   - Choose your MIDI file
   - Get ready at the piano in NTE
   - Use F5/F6/F7/F8 for controls

## 🏃 Inicio Rápido (Español)

1. **Instala las dependencias de Python:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Descarga un archivo MIDI** (o usa el Orange.mid incluido)

3. **Ejecuta el script:**
   ```bash
   python NTEscript.py
   ```

4. **Sigue las instrucciones:**
   - Selecciona idioma (1 para Español, 2 para Inglés)
   - Elige tu archivo MIDI
   - Prepárate en el piano de NTE
   - Usa F5/F6/F7/F8 para controles

## 🎮 Controls / Controles

- **F5**: Normal speed / Velocidad normal (1x)
- **F6**: Slow speed / Velocidad lenta (0.4x) - debug
- **F7**: Pause/Resume / Pausar/Reanudar
- **F8**: Stop / Detener

## 📁 Files / Archivos

- `NTEscript.py` - Main script / Script principal
- `requirements.txt` - Dependencies / Dependencias
- `README.md` - Full documentation / Documentación completa
- `Orange.mid` - Example MIDI file / Archivo MIDI de ejemplo
